From servers to a diagram

Start a New diagram, use Open saved diagram to pick one stored on the local server, or Import diagram to open a .diag.zip file; the most recently saved diagram opens automatically. The engine arranges your servers and connections automatically.

Use Edit layout to move servers and regions, then Save. Your arrangement is stored in the folder as diagram.layout.json; edited notes go back into notes.toml and edited servers into their servers/<id>.toml. Export downloads the whole diagram as one <id>-<timestamp>.diag.zip file.

After changing services or adding servers in the folder, reload the page. Existing positions are restored and new objects are placed automatically.

Start with examples/demo/. See docs/tech/authoring.md for the format. Storing and saving need node engine/serve.mjs; any modern browser works (Export and Import diagram work without it).

Host script

Collect facts from Linux servers over SSH and get a servers/<id>.toml snippet for each. The probe is read-only and needs no sudo. Run the steps on a machine that can SSH to the servers.

  1. Save the script

    Save it as host-probe.sh in the folder you will work in; the loop in step 3 reads it from there.

    Show script

  2. List the hosts
    Create hosts.txt next to it: one host (IP address or DNS name) per line. Lines starting with # are comments; blank lines are skipped.
    # web servers
192.0.2.10
198.51.100.20
app-01.example.test
    3. 

  3. Run the probe on every host
    Paste this into a terminal in that folder. It never waits for a password (hosts need key-based login), gives up on an unreachable host after 10 seconds, and saves each result to out/<host>.toml as well as showing it.
    mkdir -p out
while read -r host _ || [ -n "$host" ]; do
  case "$host" in ''|'#'*) continue ;; esac
  echo "##### $host"
  ssh -o StrictHostKeyChecking=accept-new -o BatchMode=yes -o ConnectTimeout=10 \
    "$host" 'bash -s' < host-probe.sh | tee "out/$host.toml"
  echo
done < hosts.txt
    4. 

  4. Import into the diagram
    Open or create a diagram here, click Import servers in the toolbar and choose the out/*.toml files. Pick a server type or a region, review the list and confirm; the servers are added as new servers/<id>.toml files and Save writes them.
