From servers to a diagram

Import a TOML file; the most recently saved diagram on the local server opens automatically. The engine arranges your servers and connections automatically.

Use Edit layout to move servers and regions, then Save. Your arrangement is stored beside the TOML as <name>.layout.json; edited notes are written back into the TOML. Export downloads both files with a timestamp.

After changing services or adding servers in the TOML, reload the page. Existing positions are restored and new objects are placed automatically.

Start with examples/demo/demo.toml. See AUTHORING.md for the format. Storing and saving need node engine/serve.mjs; any modern browser works.
